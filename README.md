# Academic Door / 学术传送门

面向中文读者的开放学术信息服务。读好文献，用好论文。

公开网站：<https://academic-door.github.io/>

## 公开项目

- [学术传送门 NBER 工作论文](https://academic-door.github.io/nber-working-papers-cn/)：NBER 工作论文中英文整理、归档与检索。
- [Econ Papers Daily](https://academic-door.github.io/econ-paper-monitor/)：每日追踪经济学期刊论文与工作论文。

## 说明

本站为 Academic Door / 学术传送门维护的面向中文读者的非盈利学术交流项目。中文内容由 AI 辅助翻译与人工整理，可能存在误差；论文原文、版本更新与版权信息请以原始来源为准。

本仓库仅包含公开组织主页，不包含数据采集程序、翻译缓存、API 凭据或内部运营资料。

根目录中的 IndexNow 验证文件用于通知搜索引擎公开页面更新，不包含私密凭据。
